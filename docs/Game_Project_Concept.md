
# Stickman Adventures

Stickman Adventures is a console-based Java game where
players create a stickman character and choose between
three different adventure themes.

The available themes are Fantasy Dungeon, Cyber Hacker,
and Space Explorer.

During Week 1, the focus is on setting up the project,
creating a working menu, accepting player input, and
establishing the basic game structure.

Future weeks will expand the game with character
features, missions, and gameplay mechanics.
